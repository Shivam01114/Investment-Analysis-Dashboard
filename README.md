🧠 Cognifyz Investment Analysis Dashboard
📌 Overview
This project was completed as part of my Cognifyz Internship, where I worked on 7 data analysis tasks using Power BI to explore investment trends, preferences, and patterns among individuals. The final outcome is an interactive Power BI dashboard that provides valuable insights into investment behaviors.

🚀 Key Features
✅ Data Exploration & Summary – Understanding dataset structure and key statistics
✅ Gender-Based Analysis – Analyzing investment choices across genders
✅ Objective Analysis – Exploring the relationship between savings goals and investments
✅ Investment Duration & Frequency – Studying investment timeframes and monitoring habits
✅ Reasons for Investment – Identifying common motives behind investments
✅ Source of Information – Understanding how investors gather financial knowledge
✅ Interactive Dashboard – Combining all insights into a dynamic Power BI dashboard

📊 Tools & Technologies Used
Power BI – Data visualization & dashboard creation , Data preprocessing and transformation , Data cleaning & initial analysis

📌 Insights from the Analysis
🔹 Investment Trends – Preferred investment types based on gender and objectives
🔹 Duration vs. Frequency – How long investors stay invested and their monitoring habits
🔹 Reasons for Investment – Common factors driving financial decisions
🔹 Sources of Information – Where investors get their financial knowledge

🏆 Outcome
This project provides valuable data-driven insights into investment behavior, helping financial analysts and investors make informed decisions.
